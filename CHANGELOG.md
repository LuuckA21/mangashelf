### Added
- Personal manga collection tracked volume by volume on a shared catalog of series and editions.
- Catalog: series and editions (type, status, volume count) with cover upload.
- Collection: search and filters, progress per edition, shelf of volumes toggled with mouse or keyboard.
- Login with session cookies, admin user management, first admin created from `ADMIN_*`, password change.
- Account page with personal data export and account deletion; privacy page.
- One Docker image serving API and web app; dev profile with seed data.
